Функциональные требования
1. Генерация сигналов
Реализовать консольное приложение, которое генерирует два типа сигналов:
Синусоида
    • Параметры: амплитуда, частота, количество точек (минимум 100, максимум 10000)
Меандр (прямоугольный сигнал)
    • Параметры: амплитуда, частота, количество точек
Требования к генерации:
    • Обработка некорректных входных данных с выводом понятных сообщений об ошибках
    • Генерация массива точек с координатами (время, значение)
2. Обработка сигналов
Реализовать следующие функции обработки:
    • Нахождение максимального значения сигнала
    • Нахождение минимального значения сигнала
    • Вычисление среднего значения сигнала
    • Подсчет количества пересечений нулевой линии
3. Сохранение результатов
Реализовать сохранение сгенерированных данных в текстовый файл (.txt или .csv):
    • Формат: время, значение
    • Имя файла должно содержать тип сигнала и параметры (например: sine_A5_F2_20241109.txt)
    • В начале файла добавить заголовок с параметрами генерации
